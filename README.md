# Project Introduction

The goal of this project is to create a modern, easy-to-use database website inspired by the functionality and simplicity of Bento. Bento allowed users to organize large amounts of information without requiring extensive knowledge of traditional database software. This project hopes to recreate that experience in a web-based application that can be accessed through a modern browser. Instead of forcing users to work directly with complicated database tables, queries, or programming languages, the application will provide a visual interface where information can be created, organized, searched, viewed, and updated easily.

One of the most important goals of the project is to allow the same information to be displayed in different ways. A **Table View** will display many records at once in rows and columns, making it useful for browsing a collection, sorting information, searching for records, and comparing multiple items. A **Form View** will focus on a single record and display its information using a customized layout. For example, a historical collection could have a large photograph of an artifact surrounded by fields containing its name, identification number, acquisition date, condition, value, location, and historical notes. Both views will use the same underlying database, meaning that information changed in one view will automatically be reflected in the other.

The project also aims to give users control over how their databases are organized. Rather than creating one database for one specific purpose, the application will allow users to create different **libraries and collections** for different types of information. A user could create collections for historical artifacts, photographs, books, maps, stock certificates, personal records, inventories, or entirely different subjects. Each collection could contain its own fields, such as text, numbers, dates, currency values, checkboxes, dropdown selections, notes, and images. This will allow the application to adapt to the user's information instead of requiring the user's information to fit into a predetermined format.

Another major part of the project will be the ability to customize the appearance of the Form View. Users should be able to decide which fields appear on a form, where those fields are located, how large they are, and how the information is presented. Image fields will make it possible to include photographs or scans directly with a database record, while larger text areas can be used for descriptions, research notes, provenance, or other detailed information. Eventually, the project can also support features such as saved searches, filters, smart collections, relationships between records, printable reports, data importing and exporting, and additional views for browsing image-heavy collections.

The completed product is intended to demonstrate that a powerful personal database does not have to be complicated to use. It will combine the organization and reliability of a traditional database with the visual, customizable approach that made programs such as Bento useful for personal collections. The result will be a modern database application that makes it possible to manage both simple and complex collections while keeping the information understandable, searchable, and visually organized.

Ultimately, this project hopes to create more than a replacement for an older piece of software. It is an opportunity to take the features that made Bento useful and redesign them for modern computers and web browsers. The finished application should provide users with a central place to preserve information, photographs, records, and research while allowing them to choose how that information is displayed and organized. The focus throughout the project will be on **flexibility, ease of use, customization, and long-term accessibility**, creating a database system that can grow alongside the collections and information stored within it.
